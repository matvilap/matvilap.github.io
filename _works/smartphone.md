In this project I explored using the sensors built into a smartphone to control multiple layers of a synthesizer to produce drone music. I used the OSCHook application to send phone sensor data to Max/MSP. The IMU data (acceleration and orientation), is used to control amplitude, filters, and distortion of different drone synthesizers.
